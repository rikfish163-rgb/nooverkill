# 📓 规则示例与使用反馈

[README](../README.md) 直接列出了提示词希望减少的 bad cases，以及应当保留的必要工作。网站当前八条记录是规则示例，标为 `illustrative`，不作为提示词实测效果。

欢迎提交**使用本仓库提示词之后**的真实反馈：

- [🐛 仍然存在或新出现的问题](https://github.com/rikfish163-rgb/nooverkill/issues/new?template=bad-case.yml)
- [🌱 解决的问题与好的效果](https://github.com/rikfish163-rgb/nooverkill/issues/new?template=positive-case.yml)
- [💬 查看全部使用反馈](https://github.com/rikfish163-rgb/nooverkill/issues)

请说明使用了哪版提示词、怎样加载、任务是什么，以及实际发生了什么。有使用前后对照时欢迎提供。实际报告标为 `observed`，并通过来源链接保留反馈上下文和证据；维护者根据证据决定收录。

浏览 [在线示例](https://rikfish163-rgb.github.io/nooverkill/#cases)，或查看数据源 [catalog.json](catalog.json)。案例用于校准判断，不随安装器写入 Agent 上下文。贡献细节见 [CONTRIBUTING.md](../CONTRIBUTING.md)。
