# Case catalogue

案例分为 `bad` 与 `positive`，证据分为 `illustrative`（规则示例）与 `observed`（有具体证据的实际报告）。当前种子案例均为规则示例，不是对模型效果的测试结果。

浏览 [在线案例库](https://rikfish163-rgb.github.io/agent-scope/#cases)，或查看唯一数据源 [catalog.json](catalog.json)。

- [提交 Bad case](https://github.com/rikfish163-rgb/agent-scope/issues/new?template=bad-case.yml)
- [提交 Positive case](https://github.com/rikfish163-rgb/agent-scope/issues/new?template=positive-case.yml)
- [查看全部社区提交](https://github.com/rikfish163-rgb/agent-scope/issues)

每条记录说明任务、实际行为、判断依据与合适动作。真实问题不能仅因外观相似而被排除；positive 也包括看似防御、实际必要的工作。维护者按证据决定收录，无固定比例或必过/必拒门槛。

案例用于解释和校准，不随安装器写进 Agent 上下文。需要时按 ID 引用。提交细节见 [贡献指南](../CONTRIBUTING.md)。
