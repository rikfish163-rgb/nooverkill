01 / THE WORKING AGREEMENT

Keep the work useful.

01

Find real issues.

Rare failures count when documented examples, public interfaces or actual project data can produce them. Required security and review work stays required.

02

Give complexity a job.

Hashes must save a costlier operation and change what happens next. Add wrappers, guards and migrations when the project actually needs them.

04 / PRACTICAL QUESTIONS

How does it fit your workflow?

How can I reduce overengineering in Claude Code or Codex?

Load the rules into CLAUDE.md or AGENTS.md, or invoke the NoOverkill skill for a task. It asks the agent to tie added complexity to a concrete project need, identify what each check can catch, and continue once the required work is complete.

Does this replace my existing project instructions?

The file installer preserves text outside its managed block. Explicit project requirements and higher-priority instructions take precedence. Choose the core profile if you only want the nine scope principles.

Can I use it with Cursor, Copilot, Gemini CLI or OpenCode?

Yes. The installer supports each platform's rule files and skill directories. Native marketplace plugins are provided for Codex and Claude Code. A Gemini context extension is also included.

Does it tell agents to skip security or necessary tests?

Required checks remain mandatory. Genuine issues reachable through supported usage must still be reported, including uncommon inputs. The rules constrain disproportionate remedies.
